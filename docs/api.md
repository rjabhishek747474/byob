# API Reference: BeYourOwnBoss Platform

## 1. Overview & Protocol Standards

The BeYourOwnBoss API adheres to RESTful conventions over HTTPS, standard JSON payload representations, and consistent envelope formatting across all successful and error responses.

### 1.1 Base URLs
- **Platform Management API**: `https://admin.byoboss.io/api/v1`
- **Tenant Admin API**: `https://admin.byoboss.io/api/v1/admin`
- **Tenant Storefront API**: `https://{tenant_slug}.byoboss.io/api/v1/storefront`
- **Media Asset API**: `https://admin.byoboss.io/api/v1/assets`
- **Analytics Ingestion API**: `https://{tenant_slug}.byoboss.io/api/v1/analytics`

### 1.2 Authentication & Tracking Headers
Every request must include:
- `Authorization: Bearer <JWT_TOKEN>` (for authenticated Admin/Platform requests) or session cookie `byob_session`.
- `X-Correlation-Id: <ULID>` (generated by client or injected at Edge).
- `X-Tenant-Slug: <SLUG>` (automatically parsed by Edge routing).

### 1.3 Consistent Response Envelope
All API responses follow the standard envelope schema:

```json
// Success Response
{
  "success": true,
  "data": { ... },
  "metadata": {
    "correlationId": "01J9X8V6B5Y...",
    "timestamp": "2026-10-13T01:45:00.000Z"
  }
}

// Error Response
{
  "success": false,
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "The requested product does not exist in this tenant catalog.",
    "details": []
  },
  "metadata": {
    "correlationId": "01J9X8V6B5Y...",
    "timestamp": "2026-10-13T01:45:00.000Z"
  }
}
```

## 2. RBAC Permission Matrix

| Role | Description | Allowed Permissions |
| :--- | :--- | :--- |
| **Platform Superadmin** | Global SaaS operator | `platform:admin`, `tenants:manage`, `tenants:suspend`, `billing:global` |
| **Store Owner** | Tenant creator & primary owner | `*` within tenant scope (`catalog:*`, `orders:*`, `settings:*`, `analytics:*`, `team:*`) |
| **Store Manager** | Operational admin | `catalog:read`, `catalog:write`, `orders:read`, `orders:write`, `analytics:read` |
| **Staff Member** | Fulfillment & catalog assistant | `catalog:read`, `orders:read`, `orders:update_status` |
| **Analyst** | Read-only business intelligence | `analytics:read`, `analytics:export`, `catalog:read`, `orders:read` |
| **Store Customer** | Storefront shopper | `storefront:browse`, `cart:manage`, `orders:create_own`, `orders:read_own` |

## 3. Endpoints Reference

### 3.1 Authentication Endpoints (`/api/v1/auth`)

#### `POST /api/v1/auth/login`
Authenticates a tenant administrator or team member.
- **Rate Limit**: 50 req / 5 min per IP.
- **Request Body**:
```json
{
  "email": "owner@example.com",
  "password": "SuperSecretPassword123!",
  "tenantSlug": "acme-store"
}
```
- **Response**: `200 OK`
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "01J9X8W...",
      "email": "owner@example.com",
      "name": "Jane Doe",
      "role": "owner",
      "tenantId": "01J9X8T..."
    },
    "token": "eyJhbGciOiJIUzI1Ni...",
    "expiresAt": "2026-10-14T01:45:00.000Z"
  }
}
```

#### `POST /api/v1/auth/logout`
Revokes active session tokens and clears authentication cookies.
- **Response**: `200 OK`

### 3.2 Tenant & Platform Administration (`/api/v1/admin/tenants`)

#### `GET /api/v1/admin/tenants`
Retrieves tenant account information for current authenticated scope.
- **Permissions**: `tenants:read`
- **Response**: `200 OK`
```json
{
  "success": true,
  "data": {
    "id": "01J9X8T...",
    "name": "Acme Apparel",
    "slug": "acme-apparel",
    "status": "active",
    "plan": "growth",
    "customDomain": "shop.acmeapparel.com",
    "createdAt": "2026-01-15T10:00:00.000Z"
  }
}
```

#### `PATCH /api/v1/admin/settings`
Updates store configurations (currency, tax rules, branding).
- **Permissions**: `settings:write`
- **Request Body**:
```json
{
  "currency": "USD",
  "taxRateBasisPoints": 825,
  "contactEmail": "support@acmeapparel.com",
  "analyticsEnabled": true
}
```

### 3.3 Catalog Management (`/api/v1/admin/catalog`)

#### `GET /api/v1/admin/catalog/products`
Lists products with pagination, category filtering, and search.
- **Query Parameters**:
  - `page` (number, default: 1)
  - `limit` (number, default: 20, max: 100)
  - `search` (string)
  - `status` (`draft` | `published` | `archived`)
- **Response**: `200 OK`
```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "01J9X8P...",
        "title": "Minimalist Canvas Sneaker",
        "slug": "minimalist-canvas-sneaker",
        "description": "Eco-friendly canvas footwear",
        "priceCents": 8500,
        "compareAtPriceCents": 11000,
        "inventoryCount": 142,
        "status": "published",
        "images": ["https://cdn.byoboss.io/assets/acme/sneaker-1.webp"]
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "totalItems": 48,
      "totalPages": 3
    }
  }
}
```

#### `POST /api/v1/admin/catalog/products`
Creates a new product record.
- **Permissions**: `catalog:write`
- **Request Body**:
```json
{
  "title": "Minimalist Canvas Sneaker",
  "slug": "minimalist-canvas-sneaker",
  "description": "Eco-friendly canvas footwear",
  "priceCents": 8500,
  "compareAtPriceCents": 11000,
  "inventoryCount": 150,
  "status": "published",
  "categoryIds": ["01J9X8C..."],
  "images": ["https://cdn.byoboss.io/assets/acme/sneaker-1.webp"]
}
```

### 3.4 Storefront Public API (`/api/v1/storefront`)

#### `GET /api/v1/storefront/products`
Public endpoint returning published catalog items for the resolved tenant.
- **Rate Limit**: 2000 req / 5 min per IP.
- **Headers**: Automatically resolved via `x-tenant-slug`.

### 3.5 Asset Management (`/api/v1/assets`)

#### `POST /api/v1/assets/upload-url`
Generates a pre-signed S3 upload URL for tenant media files.
- **Permissions**: `assets:write`
- **Request Body**:
```json
{
  "fileName": "hero-banner.webp",
  "fileSizeBytes": 450210,
  "mimeType": "image/webp"
}
```
- **Response**: `200 OK`
```json
{
  "success": true,
  "data": {
    "uploadUrl": "https://beyourownboss-prod-assets.s3.amazonaws.com/tenants/01J9X8T/...",
    "assetUrl": "https://cdn.byoboss.io/assets/tenants/01J9X8T/hero-banner.webp",
    "expiresInSeconds": 300
  }
}
```

### 3.6 Analytics Telemetry (`/api/v1/analytics`)

#### `POST /api/v1/analytics/events`
Ingests behavioral telemetry events from storefront sessions.
- **Rate Limit**: 500 req / min.
- **Request Body**:
```json
{
  "eventId": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "eventName": "product_viewed",
  "sessionId": "ses_01J9X9A...",
  "visitorId": "vis_01J9X9B...",
  "occurredAt": "2026-10-13T01:42:00.000Z",
  "path": "/products/minimalist-canvas-sneaker",
  "referrerCategory": "search_engine",
  "consentCategories": ["analytics"],
  "properties": {
    "productId": "01J9X8P...",
    "priceCents": 8500,
    "category": "Footwear"
  }
}
```
- **Response**: `202 Accepted`
